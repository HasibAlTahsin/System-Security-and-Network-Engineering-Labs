# System-Security-and-Network-Engineering-Labs

A collection of laboratory reports and practical coursework completed as part of the **Master's programme in System and Network Engineering (SNE) at Innopolis University, Russia**.

This repository documents hands-on academic work across computer systems, network engineering, cybersecurity, digital forensics, secure software development, DevOps, and offensive security.

---

## Overview

This repository brings together laboratory assignments completed during the Fall 2025 and Spring 2026 semesters.

The submissions demonstrate practical exploration of system administration, network infrastructure, cryptography, digital forensics, security testing, software delivery automation, and modern infrastructure technologies.

The repository primarily contains laboratory reports in PDF format, along with supporting submission materials where applicable.

## Academic Coursework

### Fall 2025 (F25)

#### 1. Computer Systems and Networks

Laboratory topics:

- System Identification
- Technological Communication
- Networking Reconnaissance and Analysis
- Linux Daemon Configuration
- Static Code Analysis

**Focus areas:** Computer systems, Linux administration, network analysis, system communication, and software code analysis.

#### 2. Networks Engineering

Laboratory topics:

- Networking Fundamentals
- IPv4 and IPv6 Addressing
- Switching, Spanning Tree Protocol (STP), and VLANs
- Open Shortest Path First (OSPF)
- Quality of Service (QoS)
- Border Gateway Protocol (BGP)

**Focus areas:** Network infrastructure, IP addressing, switching, routing protocols, network segmentation, and traffic management.

#### 3. Security of Systems and Networks

Laboratory topics:

- Classical Cryptography
- UEFI Secure Boot
- RSA Cryptography
- OpenVPN Server Configuration

**Focus areas:** Cryptographic principles, secure boot, public-key cryptography, and secure network communication.

#### 4. Unix-Based Internet Applications

Laboratory topics:

- System Booting
- DNS Server Deployment and DNS Delegation
- Secure Mail Server Setup
- Web Servers and Directory Services

**Focus areas:** Unix-based services, DNS infrastructure, email systems, web servers, and internet application administration.

---

### Spring 2026 (S26)

#### 5. Computer Forensics and Incident Response

Laboratory topics:

- Data Acquisition
- Windows File System Forensics
- Sandboxing and Malware Analysis
- SIEM Deployment for Threat Detection

**Focus areas:** Digital evidence acquisition, forensic investigation, malware analysis, security monitoring, and incident detection.

#### 6. DevOps and Security

Laboratory topics:

- Configuration Management Tools
- Continuous Integration and Continuous Delivery (CI/CD)
- CI/CD Infrastructure
- Kubernetes Basics
- Large Language Models in DevOps

**Focus areas:** Infrastructure automation, configuration management, CI/CD pipelines, container orchestration, and AI-assisted DevOps workflows.

#### 7. Offensive Technologies

Laboratory topics:

- Offensive Technologies Fundamentals
- Practical Security Exercises
- Exploitation and Security Analysis
- Malware Analysis

**Focus areas:** Offensive security concepts, vulnerability analysis, exploitation techniques, and security investigation.

#### 8. Secure Development

Laboratory topics:

- DevSecOps CI/CD
- Fuzzing for Software Security Testing
- Security Information and Event Management (SIEM)
- Mandatory Access Control (MAC)
- Penetration Testing

**Focus areas:** Secure software development, automated security testing, vulnerability discovery, security monitoring, access control, and penetration testing.
